The difference

A shape is easy. A shape you can still change is the hard part.

Most language-driven 3D tools hand back a surface. It looks right, and then the first revision costs you the whole thing. PromptCAD is built the other way round.

Mesh generation

A finished surface

  • Thousands of triangles with no idea that a hole is a hole.
  • Changing a dimension means sculpting, or starting again.
  • Sizes are whatever came out of the model.
  • Exports as a mesh, so curves arrive faceted.

PromptCAD

A parametric feature tree

  • Four named features — box, cylinder, cut, fillet — each editable.
  • Change the box width and everything downstream rebuilds.
  • Dimensions are read back out of the solid and compared to the prompt.
  • Exports as STEP, so curves stay curves.

How it works

Five stages, and none of them generate a mesh.

The pipeline is deliberately narrow. The model never writes free-form code and never touches the geometry kernel directly — it proposes operations, and PromptCAD builds them.

  1. You describe the part

    Plain English, in the panel. Three ways to work: Structured for a whole part at once, Engineering to add one operation at a time and watch each step land, and Python when you would rather write the script yourself.

  2. The model returns a plan, not code

    The answer has to be a list of operations drawn from a fixed vocabulary of 19, each with typed and validated parameters. That constraint is what makes the result editable instead of a one-shot blob.

    Local models are held to it by a GBNF grammar, so malformed output is not merely rejected — it cannot be produced. Remote models use their structured-output modes.

  3. PromptCAD builds the feature tree

    Each operation becomes a real FreeCAD object. A plate with a bored hole and filleted edges is a box, a cylinder, a cut and a fillet — four nodes, each with editable properties, in the order they were applied.

  4. It measures what it built

    After building, PromptCAD inspects the actual solid: bounding box, volume, and a measurement table per feature. Then it reads the dimensions back out of your prompt and compares them with the geometry. Ask for 60 mm and get 6 mm, and it says so rather than handing you a confident wrong part.

  5. It repairs its own mistakes, within limits

    When an operation fails or a check does not pass, the error goes back to the model and it tries again — under a fixed repair budget with a loop guard. It gives up and tells you, rather than spinning.

Vocabulary

Nineteen operations, and nothing outside them.

The window

Minimal by default, complete when you want it.

PromptCAD is built on FreeCAD, which opens with nine toolbars and roughly eighty icons. That is the right default for CAD you drive with a mouse, and the wrong one for CAD you drive by describing things — the prompt ends up a narrow strip beside a wall of buttons it does not need.

So PromptCAD starts with one short toolbar row and gives the prompt real width. Nothing has been removed: one button — or Ctrl+Shift+T — brings the entire FreeCAD toolset back, and it remembers which way you like it.

Models

Bring your own model. It finds it by itself.

PromptCAD ships without weights, so the download stays small and you are never locked to one vendor's model. Download a model and PromptCAD picks it up — there is no settings dialog to hunt through and no path to paste.

  1. Install PromptCAD

    One installer, including the inference engine. Nothing downloads behind your back later.

  2. Download a model

    Click a button below. Your browser saves it to Downloads — that is fine, leave it exactly there.

  3. Start PromptCAD

    It finds the file, selects it, and lists it in the dropdown at the top of the panel.

Already have models? If you use LM Studio or Ollama, PromptCAD lists those as well. A part-finished download is skipped on purpose — PromptCAD checks the size first, because a truncated .gguf fails deep inside the inference engine with an error that explains nothing.

Where it looks. Any of these. Drop a file in one and it is found on the next start.

%USERPROFILE%\Downloads <install folder>\models %APPDATA%\PromptCAD\<version>\models %USERPROFILE%\.lmstudio\models %USERPROFILE%\.machine\models

Providers

Local by default. Seven ways in.

Local is the default because your geometry stays yours. But model lists are fetched live from each provider rather than hardcoded — so a model released this morning is selectable this afternoon.

  • Local Bundled llama.cpp, GGUF, offline
  • Ollama Your existing server
  • LM Studio Shares its model library
  • Anthropic Claude
  • OpenAI GPT
  • Google Gemini
  • xAI Grok
  • OpenRouter Everything else, one key

Output

Getting the part out.

Because the result is real B-rep geometry rather than a mesh, it exports as real geometry.

  • STEPExact B-rep for CAD and CAM interchange. Curves stay curves — nothing is faceted on the way out.
  • STLFor printing and preview, with the mesh tolerance under your control.
  • 3D print modeGive it your build volume and PromptCAD checks the part against it, and can scale to fit.
  • TemplatesSave a part you like as a template and start the next one from it.

Requirements

What it needs.

  • SystemWindows 10 or 11, 64-bit.
  • DiskAbout 2.5 GB installed, plus whatever your model needs.
  • Memory8 GB for the recommended 4B model, 16 GB for 12B. More for the larger models above.
  • GPURecommended for local models, and used automatically when one is present.
  • NetworkOnly to download PromptCAD and a model. After that it works offline.
